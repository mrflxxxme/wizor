## #6 ПДн-резидентность (152-ФЗ) — PASS

- **Резидентность хранения:** `probe_runs.raw_response` (вывод LLM) и `visibility_metrics` пишутся в тот же PG, что и остальные контексты; `core/config.py` валидирует `data_region` как РФ-регион (`ru-central1`, Yandex Cloud) с `field_validator`, бросающим при не-РФ регионе (152-ФЗ). ✔
- **ПД конечных пользователей:** probe хранит промпт-ответы про бренд/рынок клиента (напр. «кто лидер рынка вывоза макулатуры»). Персональные данные конечных пользователей НЕ собираются и не хранятся. `raw_response` — сгенерированный моделью текст о видимости бренда, не чужой ПД.
- **Трансграничная передача:** иностранные модели (ChatGPT/Perplexity) получают ТЕКСТ ПРОМПТА через зарубежный прокси. Промпты — бренд/рыночные запросы, ПД в них нет по дизайну (генерация промптов контролируется платформой из сущностей сайта). RU-модели (Алиса/GigaChat) — дефолт, РФ-нода.
- **F5 (info):** латентный риск — если пользователь вручную впишет PII в кастомный промпт (`PUT /prompts`), он уйдёт к иностранной модели. Митигируется тем, что промпты — visibility-запросы, а не поле для ПД; будущий guard на PII в промптах — кандидат в AC. Не дефект P5.

**Вывод #6: PASS** (граница подтверждена; F5 info).

## #7 Uncertainty + #2 Honest-forecast — PASS

- **N≥5 приколот:** `runner` `max(n_runs, MIN_RUNS)`; батч `RUNS_PER_PROMPT=MIN_RUNS`. Хранится ПОЛНОЕ распределение (все N прогонов в `probe_runs`), не только агрегат (контракт probe, §6.7). `test_run_prompt_floors_to_five_runs` (n_runs=3 → 5 прогонов).
- **CI реальный:** двусторонний t-интервал Стьюдента (`uncertainty.py`, `_T_CRIT_95` df1..30, df>30 → нормальная аппрокс через `NormalDist.inv_cdf`); s=0 → полоса вырождается в точку. Не выдуманный ±.
- **Честный коллапс N<5:** `_noise_band` → `if n < MIN_RUNS: return (score,score,n)`; поле `n` в ответе несёт правду, потребитель видит N<5. Пустой вход → всё 0. `test_stability_gt_08…` (нулевая дисперсия → полоса=точка), `test_empty_input_is_safe_zero`.
- **Visibility НЕ гарантия:** нет `гарантируем`/`100%`; полоса шума всегда в ответе (`ci_lower`/`ci_upper`); score∈[0..100]; докстринги/схемы явно «диапазон, не гарантия» (§6.2/§6.7).
- **SoV-без-конкурентов:** `engine.py:155` `sov = coverage` — задокументированный fallback (нет конкурент-данных в P5), в КОДЕ не выдаётся за конкурентную долю.
  **F2 (minor):** в API-поверхности proxy-SoV не помечен — `VisibilityMetrics.sov` отдаётся числом, равным coverage, с описанием «vs конкуренты». Потребитель не отличит proxy от настоящего SoV. Честность не нарушена (значение не раздуто), но задача требовала явную метку. Fix — флаг `sov_is_proxy` / признак наличия конкурент-данных. Disposition: deferred-to-AC.

**Вывод #7/#2: PASS** (F2 minor на метку).
