# /autonomy:discuss — автономный разбор фазы (ADR-0021 D4)

Прогони front-autonomy routine для фазы **$1**. Ты заменяешь интерактивный форк-грил на автономное decide-and-log, эскалируя только там, где суждение founder'а структурно необходимо.

## Контракты (грузи первыми, JIT)
- `.claude/autonomy/escalation-policy.md` — что владеешь vs эскалируешь.
- `.claude/autonomy/judge-panel.md` — как вести широкие форки.
- `.planning/_meta/BUILD-CHARTER.md` §6 — стоячие инварианты (границы, не форки).
- `.planning/STATUS.md` + `.planning/HANDOFF.md` — где мы.

## Шаги

1. **Bootstrap.** Прочитай phase-spec для **$1** (`.planning/roadmap/$1-*.md`, HEAD-SUMMARY первым) + затронутые `contracts/<ctx>/`. Заземляй каждое утверждение в коде, не в памяти (grep, не предполагай).
2. **Перечисли форки.** Каждое реальное решение фазы. Для каждого: варианты + рекомендованный дефолт с обоснованием по рубрике оптимальности (judge-panel §Рубрика).
3. **Классифицируй каждый форк** по `escalation-policy.md`:
   - **продукт/рынок** или **tripwire-категория** → **ЭСКАЛАЦИЯ**: черновик escalation-record (формат в политике). НЕ решай. Продолжай независимые форки.
   - **agent-owned** → решай.
4. **Реши owned-форки.**
   - **Широкий форк** (архитектура/алгоритм/схема, высокий blast radius) → judge-panel: N подходов → `auditor`-рубрика → победитель + прививка.
   - **Узкий** → рекомендованный дефолт.
5. **Логируй каждое owned-решение** через `scripts/autonomy/log_decision.py` (`--kind arch --adr ADR-00NN` для архитектурного — пиши ADR тоже; `--kind impl` иначе). Передавай `--phase $1`.
6. **Эмит план.** `PLAN.md` фазы: решённые решения, декомпозиция задач, флаги `wide_fork:`/`escalated:`, pipeline-шаблон (`.claude/agents/_shared/pipeline-templates/`). Если что-то эскалировано — что **заблокировано до `/ack`** и что можно делать сейчас.

## Output
- Короткая сводка: N форков → X owned+logged, Y escalated (с escalation-records).
- Путь `PLAN.md`.
- Если ничего не эскалировано: скажи — фаза готова к автономному исполнению.

## Guardrails
- Никогда не выдумывай значения `TBD_*` (PLACEHOLDERS.md — литералы).
- Никогда не решай продукт/рынок или tripwire-форк сам, даже если дефолт очевиден — эскалируй.
- Уважай залоченный стек (ADR-0011). Отклонение — само по себе архитектурное решение → ADR + log.
- Вариант, ломающий стоячий инвариант §6, НЕ рассматривается — это блок+эскалация к architect/founder, не «решение» (escalation-policy §Инварианты).
